←Set up Termux hostMOCKUP
Three steps on the phone. The app can’t install code into Termux for you — you paste these commands there once, then come back here.
1Install Termux
Install Termux from Google Play (the Play build is current; Android 11+).
Open Play Storethen open Termux
2Install Node 24 + harness
In Termux, paste this — it installs Node, git, the harness and the mobile host plugin:
# in Termux pkg update -y && pkg install -y nodejs git npm install -g @deepseek-ai/dsh git clone https://github.com/LordGrimTaken/dsh-mobile cd dsh-mobile/host-plugin && npm install dsh plugin add link:$PWD
Copy commands~1.5 GB · a few minutes on Wi-Fi
3Start the host
Run the harness in Termux and keep it awake:
termux-wake-lock cd ~/dsh-mobile dsh web --no-open # serves 127.0.0.1
First start asks you to configure a provider (DeepSeek API key) — the same onboarding the desktop harness uses. Keep Termux in the foreground for long turns; Android may stop background apps.
When the host is up, come back and tap Detect host — pairing works entirely over loopback, nothing is exposed to the network.

←Set up Termux hostRENDER
The app exports the host plugin from inside itself — no repository clone and no account needed. Do these three steps on the phone once; the harness then runs entirely on this device.
1Install Termux from Google Play
Use the Play Store build (current, works on Android 11+ with modern targetSdk).
Open Play Store
2Export the host bundle
Writes the mobile host plugin and installer to Downloads so Termux can unzip it. The only online step later is installing the harness from npm.
Export host bundle
Exported to Download/dsh-mobile/dsh-mobile-host.zip
3Run the installer in Termux
Paste these commands. They install Node/unzip if needed, unpack the bundle and start the harness with a wake lock.
# In Termux: pkg install -y nodejs unzip termux-setup-storage # first run only cd ~/storage/downloads && unzip -o dsh-mobile-host.zip -d dsh-mobile-host cd dsh-mobile-host && bash install.sh
Copy commands
~1.5 GB for the harness · first npm install takes a few minutes on Wi-Fi. The first harness start asks for a provider API key.
4Detect and pair
When Termux says the host is running, tap Detect host. The app probes 127.0.0.1:3543 and offers Pair this host.
Detect host
The harness is @deepseek-ai/dsh from npm (public package, not this app’s repo). The host plugin itself is bundled inside DSH Mobile and exported above.
